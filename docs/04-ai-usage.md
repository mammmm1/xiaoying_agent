# 04 · AI 使用与个人贡献

## 如实声明

本项目是AI辅助生成的工程初稿，不应署为候选人独立完成。使用Codex进行题目比较、方案、代码、测试、合成资料、运行记录和文档编写。真实业务决策器接入DeepSeek；初次连接失败记录保留，后续已实际完成真实模型评估与原始证据复核。

AI承担了：原生工具调用循环、参数及硬约束、SQLite幂等和断点、DeepSeek适配、离线规则模拟器、对抗与协议测试、场景评估脚本、文档。未使用其他子Agent，也未使用Agent框架。

用户已承担的可确认工作：选择第2题、确认官方服务、在本地填写密钥，要求对齐检查与启动演示，并在后续要求重试连接。没有证据表明用户已独立修改具体代码或完成个人实测，因此不替用户虚构这些贡献。

## 验证范围

AI实际执行36项测试、13组离线场景和13组真实DeepSeek模式场景。首次真实检查12/13；无素材合理追问暴露评估器状态预期过窄，修正并增强证据要求后，同批原始日志复核13/13。首次汇总、Trace与文件哈希保留，未编造调用或改写日志。接口单测与Mock仍不作为真实模型效果依据，详见03-evaluation.md。

## 候选人贡献与投入

候选人自报累计投入约 **2.5小时**。这是本项目的个人参与估算，包含交流与评审过程；没有单独统计独立编码、手动执行命令和等待工具的分钟数，不将AI执行时间折算为个人手写代码时间。

| 工作 | 实际参与与责任 |
| --- | --- |
| 选题与交付范围 | 候选人确认第2题，选择先完成核心CLI链路 |
| 模型与凭据 | 候选人提供官方DeepSeek服务，在本地配置密钥；密钥未进入仓库 |
| 质量与隐私要求 | 候选人要求逐项对齐、启动演示、重试真实连接，并明确禁止上传隐私 |
| 工程实现 | AI完成主要源码、测试、资料、执行、文档及Git操作；候选人未声明独立手工实现全部代码 |
| 材料理解与复盘 | 按实际代码补充模块说明和问题分析，供候选人审阅与复现；文档不作为已经掌握知识的证明 |
| 异常诊断与迭代 | 候选人提出“先定位分析，再交由AI修改”的协作方式；已提供3组独立演练，个人诊断尚未提交 |

## 对实现的理解说明

理解材料见 [07-understanding.md](07-understanding.md)，覆盖模型与工具的分工、状态与幂等、预算时间口径、真实模型证据与Mock边界。它依据实际源码与运行记录整理，没有把尚未发生的个人修改写成履历。

本项目的关键判断是：模型可选择下一动作，硬性预算、截止时间和保存结果由代码与数据库核验；生成了脚本或估算可行，不等于已经保存方案。成功工具结果应保留，失败应成为下一轮模型观察。

## 异常定位的下一轮协作

已经实际复现外部费率表、素材库更新及同请求ID修改预算三类情形，报告在 `examples/exercises/`。前两类暴露输入资料校验与异常回传方面的缺口；第三类用于辨别正常业务保护和程序缺陷。它们是额外演练，不混入正式验收通过率。

候选人接下来按 [分析模板](08-debugging-lab.md) 提交复现、定位和修改建议。AI随后依据分析实现修改、补充回归验证并记录差异。当前状态为**已复现，待候选人分析，尚未修复**；不预先声称个人诊断或代码贡献已经完成。

密钥仅保存在本地.env，Git和交付压缩包排除该文件；未把密钥作为测试素材或写入报告。
